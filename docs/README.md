# CGeV documentation

The repository documentation is grouped by purpose:

- [`deployment/`](deployment/) — Docker, ShinyProxy, rootless, native, and Oracle deployment guides.
- [`releases/`](releases/) — installer publication guidance, release notes, and release checklists.
- [`user_manual/`](user_manual/) — source and build tooling for the public user manual.

The PDFs served by the web application are kept in [`www/docs/`](../www/docs/).
