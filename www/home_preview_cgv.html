Search modes

Two workflows for gene-centered comparison.

CGV provides two complementary workflows: Multi-Gene Search for comparing several genes within one organism, and Cross-Species Gene Search for comparing one gene across multiple organisms. Live suggestions, local aliases, and explicit ambiguity resolution help connect the query to the intended annotated locus.

Alignment

Align every transcript from a multi-isoform gene, or compare representative structures across organisms.

When a Multi-Gene result contains at least two transcripts for the same gene, CGV enables a dedicated transcript alignment with gene selection, translated CDS/CDS/exon modes, transcript ordering, and an identity threshold. Cross-Species analyses add Synteny, LASTZ Blocks, and MultiPIP.

Why CGV was built

Comparative gene analysis without switching between disconnected tools.

Gene-centered comparative analysis often requires genome browsers, sequence databases, annotation files, orthology resources, alignment tools, and plotting scripts. CGV brings these steps into a single browser-based workflow.

Genome browsers are powerful but not optimized for side-by-side gene structure comparison.
Search, alignment, inspection, annotation and export are usually fragmented.
CGV unifies gene-centered comparison in a guided visual workspace.

The problem: Genome browsers are powerful for locus inspection, but side-by-side comparison of gene structures, transcript variants, and exon organization across organisms often remains fragmented.

The workflow gap: Researchers frequently move between databases, browser tabs, command-line tools, spreadsheets, and static plots to answer a single comparative gene question.

The CGV approach: CGV integrates search, gene model visualization, transcript inspection, cross-species comparison, functional annotation, analytics, and export in one guided interface.

Scope

Focused on gene-centered structural interpretation.

CGV is designed for visual, comparative, and annotation-aware exploration of gene structures. It complements upstream assembly/annotation tools and downstream statistical or evolutionary analyses.

Designed for comparative gene, exon and transcript structure analysis.
Not designed for RNA-seq quantification, variant calling, assembly or phylogeny.

Designed for

  • Comparative gene and exon structure analysis across organisms
  • Transcript variant inspection within annotated genes
  • Cross-species representative gene model comparison
  • Exon-level structural correspondence and conservation views
  • Interactive gene metrics, sequence composition and genomic context
  • Preloaded references plus custom genome and annotation uploads
  • Exportable plots, tables, promoter sequences and reusable sessions

Not designed for

  • Differential expression, isoform switching or abundance testing
  • Variant calling, SNP/INDEL analysis or RNA-seq quantification
  • Whole-genome browsing or large-scale genome navigation
  • De novo genome or transcriptome assembly
  • Phylogenetic inference or protein 3D structure prediction
  • High-throughput genome-wide batch screening

Troubleshooting & Tips

Common checks for reliable gene searches and clear outputs.

Most issues are related to gene naming, organism selection, annotation structure, uploaded file compatibility, or very large comparisons. These checks help validate the analysis before exporting results.

Check genome and annotation file formats.
Try aliases or external gene lookup when a gene is missing.
Scale up gradually and save/export before closing.

Data inputs

  • Use a genome file together with a matching annotation file
  • Supported genome formats include .fa, .fasta, .fna, .fa.gz and .2bit
  • Supported annotation formats include .gff3 and .gtf
  • Preloaded and uploaded organisms can be combined when appropriate

If a gene is missing

  • Check spelling, capitalization, aliases and organism-specific identifiers
  • Confirm that the correct organism and assembly are selected
  • For uploaded annotations, verify gene, transcript, exon, CDS and UTR features
  • Use external lookup options when local annotation matching is insufficient
MyGeneNCBI GeneUniProtEnsembl

Performance tips

  • Start with fewer genes or organisms, then scale up once results look correct
  • Use Compact view for broad inspection and Detailed view for selected genes
  • Open analytics panels after narrowing the result set
  • For alignment-heavy analyses, begin with smaller genomic windows

Sessions & display

  • Save a session when you want to resume the same workspace later
  • Restore previous sessions from Settings
  • Use dark mode, theme options or colorblind-friendly palettes for dense comparisons
