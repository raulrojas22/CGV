Why CGV was built

Turn the motivation into a before/after story.

The problem, gap and audience are easier to understand as a single toolchain map: many scattered steps collapse into one guided visual workspace.

Genome browsers are not optimized for side-by-side gene structure comparison.
Search, alignment, inspection and export are usually fragmented.
CGV helps biologists, bioinformaticians, educators and students.

The problem: locus browsers are powerful, but they do not naturally produce clear comparative gene-structure views.

The workflow gap: users often jump between browsers, command-line tools, scripts and static plots.

The CGV answer: search, visualize, align, analyze and export inside one guided interface.

08
Scope

Define the boundary without making it feel defensive.

A scope section should help users route their workflow correctly: CGV is for gene-centered structure interpretation, not expression, assembly, variant calling or phylogeny.

Designed for comparative gene and exon structure analysis.
Not designed for RNA-seq quantification, variant calling or assembly.

Designed for

  • Comparative gene and exon structure analysis across organisms
  • Aligned exon-level relationships in a cross-species context
  • Interactive gene metrics, transcript structure and sequence composition
  • Preloaded references with custom genome and annotation uploads
  • Publication-ready exports: plots, tables and sequences
  • Session save and restore for reproducible review

Not designed for

  • Differential expression, isoform switching or abundance testing
  • Variant calling, SNP/INDEL analysis or genotyping
  • Whole-genome browsing or large-region navigation
  • De novo genome or transcriptome assembly
  • Phylogenetic inference or population genetics
  • Protein 3D structure prediction or clinical diagnostics

Troubleshooting & Tips

Practical checks, shown as a compact support strip.

Most issues come from query spelling, organism selection, annotation structure or display settings. This layout keeps the guidance visible without turning the home into a manual.

Check genome and annotation file formats.
Try aliases or external gene lookup when a gene is missing.
Scale up gradually and export before closing.

Data inputs

  • Use matching genome and annotation files
  • Check .fa, .fa.gz, .2bit, .gff3 and .gtf formats
  • Use the correct genome build

If a gene is missing

  • Try symbol aliases or ID variants
  • Confirm that an organism is selected
  • Verify annotation gene/transcript features
MyGeneNCBI GeneUniProtEnsembl

Performance tips

  • Start with fewer organisms or genes
  • Use compact view for dense comparisons
  • Open analytics panels selectively

Sessions & display

  • Save .rds sessions regularly
  • Restore from Settings when needed
  • Use theme and display options for readability
